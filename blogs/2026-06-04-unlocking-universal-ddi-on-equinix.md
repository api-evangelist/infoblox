The Infoblox and Equinix partnership enables cloud-first DDI deployment on Equinix Network Edge, allowing organizations to run DNS, DHCP, and IP address management services as virtual network functions with centralized SaaS control. The integration brings Universal DDI capabilities to Equinix's global network fabric.
